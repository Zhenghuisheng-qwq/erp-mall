## A：COMMON 来源缺陷

原 `planSkuLines` 把 COMMON 写入 `commonAttrs` 后直接返回，SKU 来源仅由 VARIANT 固定步骤与后续组合构成。因此带 COMMON 的完整性证明缺失，模板兼容创建事务拒绝新对象。

修复在分流 COMMON / VARIANT 前记录当前选中路径中的实际值节点，再按路径顺序拼接本条组合的尾部节点并去重。COMMON 仍留在公共属性，不进入 `variantAttrs`；名称、候选范围、规格身份及完整性检查保持原逻辑，没有历史数据批量补写。

原始 HEAD 的逻辑通过 Vite 测试模块替换独立执行，已复现公共属性有包装但来源缺少包装节点，见 `plan-baseline/result.json`。当前四组测试均使用真实 Store 提交：COMMON 有 / 无 × 发布兼容配置有 / 无。每组 plan 为 2 条、model 为 4 条；兄弟包装节点未混入；失败零半成品、重试不重复。证据为 `regression-final/r01-plan/output.txt`。

## B / C：目录、实例、范围与生效

目录以稳定 ID 定义销售定位、物料策略、允许值限制和原命名入口；名称、说明和可用状态可以维护，功能类型固定，不执行脚本。目录未绑定分类或产品类型。

实例位于具体 VALUE 节点的 `businessConfigs`，保存实例 ID、定义 ID、模型 ID、节点 ID、参数、启用状态和显式 scope。节点不是新规格分支，销售定位不是 ProductGrade，物料策略不是 ProductFamily 复用或请求幂等。

- 销售定位：`hot` / `not-hot`，界面为畅销 / 不畅销。
- 物料策略：`independent` / `shared`，界面明确显示仅策略、尚未共用建档。
- `current` 仅命中当前值；`subtree` 沿真实父子路径动态解析，包括后来新增的下级；兄弟和其他模型不受影响。
- 缺省或非法 scope 拒绝保存。同一节点的重复定义、重复实例身份拒绝保存。
- 目录停用禁止从目录新增实例，保留已引用实例；复制已有模型保留其已有配置。引用中的目录项禁止删除，历史发布引用也受保护。
- 命名不建立新实例或第二套数据。统一入口调用原命名编辑器，显示原规则和来源，继续沿用最近祖先继承。适用配置仍用原专用机制。

保护性冲突规则：单条命中生效；同一作用点上参数完全等价的配置合并展示来源；不一致显示冲突及节点。允许值集合仅比较是否等价，不取交集、不覆盖。冲突草稿可保存、停用或删除修正；受影响模型不能发布，受影响路径不能用于新业务执行；其他模型和旧发布版继续可读、可用。这不是最终业务优先级的确定。

## D：路径限值的实际接入

允许值限制只接受 `subtree`，目标属性必须在附着值的真实下级路径中，允许值引用现有词典属性 ID 与既有字符串值身份。空集合、重复值、失效目标、失效词典值和无意义 scope 拒绝保存。

统一解析器用于新增值候选、原位改值候选、大纲 / 幕布重绑和实际重绑命令。设计器结构事务在落入编辑历史前检查新增违规；拖拽重挂先校验脱离 live state 的候选；模型复制检查源配置；发布检查完整树；V3 组合及新建提交也检查受影响路径。不能靠直接构造越界草稿绕过发布。

导入 / 恢复保留原配置与越界草稿，具体节点可在面板定位修正，不自动删值、剪枝或清空数据。结构修正允许减少既有问题，不新增违规。新增限制自身造成旧草稿越界时，可以保存配置继续修正，但发布被阻止。

## E：版本、编辑历史与存储

使用 V15 的可选扩展，不进行全库版本升级或历史补写。字段缺省按原行为读取；默认目录惰性读取，目录维护后仍保存于同一 AppData。

发布深拷贝节点实例并冻结对应定义，以及限值目标词典的 ID / 名称 / 值集合。目录后续改名或停用、草稿配置变化不改旧快照；后续词典失效会提示草稿问题，旧发布限值仍按冻结信息解释。配置参与发布内容比较，配置单独变化可发布新版本。销售定位 / 物料策略不进入规划身份，因此沿用原 PLN。限值改变合法性时使用原发布检查与规划对账，不改历史 MAT 或编号。

复制重建实例 ID、模型 ID、节点 ID，清除来源模型的冻结副本。JSON 导出、规范化读取和恢复保留实例。未知定义 / 类型保留原文并显示不支持，不能当作空配置发布；可以明确删除或修正，未重写其原文。

新增配置增删改使用原 `captureEditor` / `editorEntry` 历史，原命名数据、原生文本编辑和模型切换保护不另建框架。保存中阻止重复提交 / 关闭 / 路由切换；陈旧节点依据、配额失败或外部更新拒绝写入，面板保留输入。所有写入复用原 Store command、catalogPersistence、Web Lock / 本页队列、revision 和恢复机制，没有新增 LocalStorage 业务键。
